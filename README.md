### About the Project
As part of my **personal project**, I created my **bilingual professional portfolio (FR/EN)** showcasing my skills in **Artificial Intelligence** and **Astrophysics**.  
This project is **my first experience in web development**, designed to introduce myself and highlight my achievements.

---

### Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript  
- **Libraries:** Swiper.js, MixItUp, RemixIcons  
- **Hosting:** GitHub Pages  
- **Form Handling:** Formspree 
- **Responsive:** Mobile-first design
